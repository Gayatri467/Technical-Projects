
# FRR and MRT Lab

## 1. Overview

This project focuses on building a containerized BGP routing laboratory using FRRouting (FRR) and Docker Compose.

The lab explores BGP router configuration, communication between routing containers, and MRT-based BGP routing data collection.

The main objective is to understand how BGP routing works in a containerized environment and how routing information can be collected for further analysis.

## 2. Project Objectives

- Set up a BGP routing environment using FRRouting.
- Deploy routing components using Docker Compose.
- Configure BGP routers and routing parameters.
- Establish BGP sessions between routers.
- Explore MRT-based routing data collection.
- Verify routing information and router connectivity.

## 3. Technologies Used

- FRRouting (FRR)
- Docker
- Docker Compose
- Linux / Ubuntu
- BGP (Border Gateway Protocol)
- MRT (Multi-threaded Routing Toolkit)

## 4. Project Components

### FRRouting (FRR)

FRR is an open-source routing software suite used to configure and manage routing protocols, including BGP.

### Docker Compose

Docker Compose is used to define and run the containerized routing environment.

### BGP

Border Gateway Protocol is used to exchange routing information between autonomous systems.

### MRT

MRT provides a format for storing and collecting routing information, including BGP routing table data and updates.

## 5. Project Workflow

1. Prepare the Linux environment.
2. Build or configure the FRR Docker image.
3. Define the routing environment using Docker Compose.
4. Configure BGP routers.
5. Establish BGP routing sessions.
6. Enable MRT-based routing data collection.
7. Verify routing connectivity and collected data.

## 6. Expected Outcomes

- A containerized FRR routing laboratory.
- BGP router configuration and session establishment.
- Experience managing routing containers using Docker Compose.
- Understanding of MRT-based routing data collection.

## 7. Conclusion

This project demonstrates the use of FRRouting and Docker Compose to build a containerized BGP routing laboratory. It provides practical experience with BGP configuration, routing environments, and MRT-based routing data collection.
