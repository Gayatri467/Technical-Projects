# MRT-Based BGP Routing Data Analytics Using DuckDB and Parquet

## Overview

This project focuses on processing and analysing historical BGP routing data obtained from MRT datasets. It uses Apache Parquet for storing processed routing data and DuckDB for efficient analytical queries.

The project also includes a Flask-based web dashboard for displaying routing statistics and visualizations.
