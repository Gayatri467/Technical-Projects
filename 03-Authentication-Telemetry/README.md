# Authentication and Telemetry Experiments

## Overview

This project explores application authentication using ZITADEL and OpenID Connect (OIDC). It includes configuring an authentication application, setting login and redirect URLs, and testing the login flow.

OpenTelemetry components were also explored separately to understand application observability and telemetry collection.
